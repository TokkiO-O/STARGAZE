# STARGAZE

为 SillyTavern 角色制作头像拼贴的扩展，也提供独立运行的离线创作工作台。当前为 **1.0.0 开发版**。

十套主题，每套提供九种按尺寸分别设计的排版：奶盐学园、港风旧画报、千禧辣妹、法式蕾丝、工业废土、童话绘本、巴黎信笺、复古集邮、哥特古堡、韩系甜酷。

默认只需一张角色头像，副图使用同一头像的不同取景；每张副图也可以独立换图。主题示意图中的「预览」是文字占位，使用时会显示当前角色的头像。

## 安装

在酒馆的扩展管理中点击「安装扩展」，填写：

```text
https://github.com/TokkiO-O/STARGAZE.git
```

安装后刷新页面，从魔法棒菜单打开 **STARGAZE 头像拼贴**。也可以在扩展设置中打开主题素材管理。

手动安装时，将核心 ZIP 解压到酒馆的第三方扩展目录；进入 `STARGAZE` 文件夹应直接看到 `manifest.json`、`index.js` 和 `style.css`。

## 选择主题

打开 **主题素材 · 自选安装**，点击所需主题的「安装本主题」。扩展已连接本项目的素材发布，无需填写仓库链接。每次只下载选中的主题，已存在的共用素材会复用。

也可以点击「导入本地主题包」，选择一套 `.stargaze.json` 文件。主题素材包与可编辑模板文件是两种文件：前者在这里安装，后者从编辑器的「导入」入口载入。

安装期间可以关闭安装窗口或编辑器，请保留酒馆页面，直到收到完成提示。重新打开安装窗口可查看进度、错误原因和已安装状态。安装完成后九个尺寸均可使用，刷新页面仍会保留。

扩展直接连接本项目的官方素材源，兼容酒馆默认的下载配置，核心仍保持轻量。下载失败时可以重试，或导入对应的本地主题包。

## 编辑与创作

- 逐层调整位置、尺寸、旋转、层序、分组与锁定，支持撤销和重做。
- 放大取景，分别调整主图与副图；调整亮度、对比度、饱和度、冷暖或应用调色预设。
- 在「创作工具」中管理角色方案、查看九尺寸总览，并选择要同步的尺寸与内容。
- 收藏素材、添加标签、保存素材组合，通过快捷栏点击或拖入画布。
- 保存历史稿件，在示例聊天中预览效果；导出前检查缺图和排版问题。
- 为自制模板填写封面、标题、作者、介绍和素材来源。

## 保存与分享

「保存」保留当前角色稿件；「导出」生成包含该角色方案、历史稿件和所需图片的备份；「导出模板」分享当前尺寸或九尺寸完整模板；「存为图片」输出 PNG。

主题素材保存在酒馆用户文件中，角色稿件和自行上传的图片保存在当前浏览器。换设备前，请导出角色备份或完整模板。收藏和素材组合属于当前浏览器的共用素材库。

## 离线创作工作台

离线工作台使用 `STARGAZE-DLC-1.0.0.zip`。解压后使用 Edge 或 Chrome 打开 `dlc.html`，在里面选择主题安装或本地导入，修改模板后导出完整 JSON，再导入酒馆编辑器。

`gallery.html` 用于查看已安装主题的九尺寸总览。默认使用「预览」文字，也可临时上传自己的图片查看搭配。

## 更新

在酒馆扩展管理中更新 STARGAZE，然后刷新页面。已安装的主题和已保存的稿件可继续使用。更新主题素材时，打开「主题素材 · 自选安装」检查主题更新，再选择需要更新的主题。

代码更新与主题素材更新分别进行；开发期间产品版本继续保持 **1.0.0**。
